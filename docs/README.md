# Documentación del proyecto

Documentación de arquitectura del **Sistema de Banco de Preguntas Saber Pro**, primera
iteración (primer corte). Proyecto de curso de Ingeniería de Software II, Universidad
del Cauca, periodo 2026.2.

| Documento | Contenido |
|---|---|
| [01 · Historias de usuario](01-historias-de-usuario.md) | Las cuatro historias de la iteración con sus criterios de aceptación y su trazabilidad hasta el código y las pruebas |
| [02 · Prototipos y usabilidad](02-prototipos-y-usabilidad.md) | Prototipos de la interfaz, pantallas implementadas y evaluación de usabilidad |
| [03 · Planificación del Sprint 1](03-planificacion-sprint-1.md) | Historias, responsables y tablero de Jira |
| [04 · Modificabilidad](04-modificabilidad.md) | Atributos de calidad relevantes y escenario de calidad de modificabilidad |
| [05 · Arquitectura (C4 y UML)](05-arquitectura-c4-uml.md) | Estilo arquitectónico, modelo C4 y diagramas UML |
| [06 · Patrones y decisiones](06-patrones-y-decisiones.md) | Patrones de diseño, principios SOLID y decisiones de diseño |
| [07 · Pruebas y repositorio](07-pruebas-y-repositorio.md) | Pruebas unitarias, organización del repositorio y trabajo en equipo |

Los diagramas de secuencia, clases y estados están escritos en
[Mermaid](https://mermaid.js.org/), que GitHub muestra directamente en la página.
